# MyFinance 2.2 — 現金流與極簡首頁（驗收版）

從 2.1 原始程式修改，保留原有 Firebase project、workspaces、accounts、transactions、角色、離線本機資料庫與捷徑 REST 欄位。

## 更新
1. 先連線確認待同步交易為 0，將每個帳本匯出 JSON 至私人 iCloud Drive；備份 GitHub 原版本。
2. 將 index.html、reports.js（新增）、offline.js、sw.js、manifest.json、icon.png 一次上傳至原 GitHub Pages repository 根目錄，等待 Pages 部署。
3. 關閉 Web App 後連線重開，確認設定頁顯示 v2.2；如仍是舊版，再重新開啟或使用「重新載入程式」。不要清除網站資料。
4. 既有 V2.1 Firestore Rules 不需更新；完整包內附原樣規則供比對。不要覆寫自己額外設定的規則。
5. 建議先用本機範例或獨立測試帳本，驗證首頁、投資轉帳、資產及兩部手機同步，再正式使用。

## 統計
首頁採實際現金流口徑：cash / bank 為現金範圍；買股票是銀行流出，投資賣出轉回銀行是流入；現金與銀行內轉不計；信用卡刷卡增加負債但繳款才列流出；現金退款列流入；其他資產轉入/提領及貸款本金亦列相應流量。起始餘額、估值不列現金流。資產頁依同一筆資料計算資產及負債，不重複扣除轉帳。舊帳戶類型會用目前設定回算歷史報表，若變更類型可能改變歷史分類。

## 限制
投資頁為帳戶級手動估值，沒有券商即時行情、持股/股數成本或精確報酬率。扣除轉帳後的價值變化不是精確損益；期初餘額不一定是成本。資產全部期間圖表最多抽樣 12 個日期。大分類只用於分析，不增加記帳步驟。保留原本分類新增、改名、圖示與顏色，不提供永久刪除歷史分類。沒有新增跨帳本合併及共同分攤。離線緩存與隊列沿用 V2.1；尚未驗證 iPhone 實際離線重開及 Firebase 權限。沒有修改你的 GitHub 或 Firebase。
