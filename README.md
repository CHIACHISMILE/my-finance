# MyFinance 2.3 — 累計現金餘額（驗收版）

## 更新方式
1. 連線確認所有帳本待同步交易為 0，匯出 JSON 至私人 iCloud Drive。備份 GitHub 及原本的 Firestore Rules。
2. Firebase Console → Firestore Database → Rules，發布新版 firestore.rules（如有自行修改請合併，不要直接覆蓋其他規則）。新版只增加帳戶可選布林欄位 cashBalance 的驗證，不改動成員或交易權限。
3. 一次上傳 index.html、reports.js、offline.js、sw.js、manifest.json、icon.png 至原 GitHub repository 根目錄。確認 Pages 部署，關閉再開啟，確認設定版本 v2.3。兩位使用者皆更新後再修改現金範圍；舊客戶端編輯帳戶可能移除新欄位。
4. 使用假資料驗收跨月餘額、現金範圍、投資轉帳及兩機同步；不需重建帳本或捷徑，不要清除網站資料。

## 財務計算
- Balance = 截至選定期間最後一天（不晚於今天）的現金類帳戶餘額總和，含起始餘額、歷史交易及現金帳戶餘額調整。不新增月結轉交易。
- 預設 cash / bank 納入現金範圍。帳戶編輯可改為計入／不計入；信用卡及貸款永遠排除。證券未投資現金需單獨建立帳戶才可與股票市值區別。封存帳戶剩餘現金仍計入。現金範圍變動會回算歷史，不是日期生效設定。
- 首頁收入／花費為選定期間流入／流出；投資轉入為流出，投資提領為流入，現金類帳戶間互轉不計。信用卡刷卡不計，還款才計；估值調整不列收支。
- 圓環：正餘額時以剩餘現金與期間流出作分母，非儲蓄率；負餘額顯示缺口，無資料灰色。分析頁另外呈現期間流入減流出及期初至期末對帳。新帳戶初始餘額與現金調整分列，不誤算收入。
- 淨資產及投資報表沿用舊版計算。所有金額仍為整數台幣。

## 限制
已執行 Node VM 52 項斷言及語法檢查；未實際部署 Firebase、驗證安全規則或 iPhone 離線操作。投資仍為帳戶級手動估值，無即時行情；無跨帳本合併及共同分攤。沒有修改你的 GitHub 或 Firebase。
