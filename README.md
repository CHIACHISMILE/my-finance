## 財務口徑
- 指定月份、半年、年度、自訂期間：Balance = 期間現金流入 − 期間現金流出。期初餘額和調整不當作收入。
- 全部時間：Balance = 所有已納入現金範圍帳戶的實際餘額；含起始餘額、歷史流入流出及現金調整。不是新增結轉交易。帳戶設定改變會回算歷史。
- 首頁選月份或全部；分析頁可加選半年、年度和自訂。會記住上次所選期間；從進階分析返回首頁時保持同一期間。
- 全部流出：以現金類帳戶為範圍，投資投入、定存／押金轉入、還款等皆是流出。現金類帳戶之間互轉不計。信用卡刷卡不算現金流出，繳款才算。
- 實際消費：按 expense 原交易日統計（含刷卡），排除投資與轉帳；refund 獨立顯示，淨消費 = 消費總額 − 退款。為避免負數扇形，圓環按退款前的正數消費金額分配。
- 全部時間的 Balance 圓環比例是累計流出與剩餘現金的對照，並非儲蓄率；負餘額以玫瑰色缺口表示。銀行、現金預設納入，信用卡與貸款排除，其他資產可自行設定。
- 投資、押金等請用轉帳，並建立相應帳戶。估值調整只改帳戶餘額，不當作一般收入或消費。

## P0 改善與限制
- 離線啟動會依登入身分從可用本機帳本挑選，避免上次帳本已無快取時找不到其他帳本。登出清除該身分的快取，待同步交易須先處理。原本的 IndexedDB 佇列和交易版本檢查保留。
- 同步期間暫緩舊快照，寫入確認後重新訂閱雲端，減少舊快照覆蓋已確認交易的風險。雲端競態尚未實機驗證。
- 五種模擬螢幕寬度通過月份／日期、分類及選單排版和記帳鍵盤檢查；未驗證真實 iOS 鍵盤、安全區、Service Worker 離線重啟、IndexedDB 持久化或 Firebase 授權與多人同步。
- 離線權限以最近同步狀態為準；權限撤銷須待連線才能得知。離線快取不等於獨立加密的保險庫，勿在不可信裝置使用。iOS 可清除網站儲存，請定期備份。
- P2/P3 尚未新增：共同分帳、跨帳本合併、精確投資報酬率、即時股價、預算等。
